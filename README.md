# Wanderlight

A small text-adventure game built in Python, developed as a practice project
simulating a real software team's workflow — branches, pull requests, code
review, and testing — with the help of AI as a mentor/reviewer.

## About

You play a traveling messenger who's lost their way home, passing through a
handful of small towns along the route. This project is intentionally small
in scope: the goal isn't a big game, it's practicing how a real engineering
team works together on a codebase.
