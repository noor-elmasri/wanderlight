# Team — Loom & Ledger

A small (fictional) indie studio making text-based adventure games,
created as a practice project to simulate a real software team's
workflow.

> **Note on authorship:** Sam, Priya, Jordan, and Marcus are fictional
> personas, created with the help of AI (Claude), used to simulate
> realistic team roles, tickets, and code review. They do not have
> GitHub accounts and have made no commits. Every commit, issue, and
> pull request in this repository was written and made by Noor
> (noor-elmasri), including content drafted with AI assistance in
> their voice. This repo exists purely as a learning exercise.

## Sam — Tech Lead / Senior Engineer (fictional)
Owns the core engine architecture. Reviews every PR for code quality
and design consistency.

## Priya — Gameplay Engineer (fictional)
Builds game systems: rooms, inventory, combat. The most technically
hands-on person on the team besides Sam.

## Jordan — Narrative Designer (fictional)
Writes story content, room descriptions, and dialogue. Not very
technical — files tickets in plain, non-code language.

## Marcus — QA / Playtester (fictional)
Plays the game daily and files clear, well-reproduced bug reports.
The most precise ticket-writer on the team.

## Noor — Trainee (real — that's you)
New hire, learning the codebase, the team's git workflow, and how to
turn tickets into shipped, reviewed code. The only real person on
this project.
